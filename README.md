# ToolsKit (v5 build)

Static site generated by Python 3 standard library only. No frameworks, no runtime dependencies for the build. Output goes to `dist/`.

## Commands
    python3 build/build.py            # build dist/, sitemap, robots, llms.txt, vercel.json, docs/url-map.csv
    python3 build/build.py --strict   # fail while launch blockers remain
    python3 build/check.py            # static audit of dist/ (links, SEO, JSON-LD, wording, scripts, stale files)
    python3 build/serve.py 8766       # local server mimicking Vercel (404, redirects, cleanUrls, headers)
    python3 build/test_browser.py     # Playwright: search cases, pages x 5 viewports, tool smoke tests
    python3 build/test_ux.py          # Playwright: tool behaviour, a11y, touch targets, CSP, CV/PDF/image regressions
    python3 build/test_links.py       # crawl of the built site (both URL styles via URL_STYLE)
    python3 build/test_perf.py        # CLS and page weight (slow, several minutes)
    python3 build/test_i18n.py        # multilingual readiness guard
Env overrides: `SITE_URL`, `URL_STYLE` (html|clean), `BUILD_DATE`.

Test dependencies (not needed to build): `pip install playwright pillow pypdf`, plus a Chromium for Playwright.

## Layout
- `site.config.json` site name, `siteUrl` (+ `siteUrlConfirmed`), `urlStyle`, languages, `contactEmail`, `operatorName`, `frameAncestors` (default `'none'`), analytics switch.
- `src/data/` `tools.json`, `categories.json`, `search.json` (synonyms by tool id and language, unsupported-intent patterns).
- `src/locales/<lang>.json` UI strings. `src/content/<lang>/*.html` long pages (home, about, privacy, terms, 404).
- `src/tools/<id>/` per-tool `panel.html`, `script.js` (published as the external file `assets/tools/<id>.js`), optional `extra.css`.
- `src/assets/` css, js, vendor libraries. Header, footer and nav exist only in `build/build.py`.

## Security notes
- CSP is strict for scripts: `script-src 'self'`, no inline scripts. Every tool script is an external file. `style-src` still allows inline styles (style attributes).
- `frameAncestors` `'none'` blocks embedding in iframes (for example Google Sites). Change it in `site.config.json` only on purpose.
- Assets under `/assets/` are served `immutable` for one year. Own files carry a `?v=<hash>` query. Vendor libraries are not versioned: rename the file if you ever replace one.

## Add a tool
Add an entry to `src/data/tools.json` (including `next` links), add `src/tools/<id>/panel.html` and `script.js`, add synonyms in `search.json`, rebuild, run check and tests.

## Add a language (not launched)
English only today. `build.py` stops with an error if more than one language is enabled, because the hreflang and language-selector path is not implemented. Tool data (`tools.json`) and tool scripts still hold English strings, so those need moving to locale files first.

## Deploy (Vercel)
Output directory `dist`, no build command (commit `dist/`). `vercel.json` is generated. Do not deploy until launch blockers are cleared.

## Launch blockers
`build.py` prints them; `--strict` fails on them: unconfirmed domain, no contact email, no operator name. Privacy and Terms are drafts and need legal review.

## Verify after the first deployment (not testable offline)
Response headers and compression as delivered by Vercel, HSTS, redirects on the real domain, Lighthouse on the live URL, real iPhone/Safari and Android/Chrome checks, real file pickers and downloads.
